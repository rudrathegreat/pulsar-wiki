# PulsarWiki instruction entry point

Before answering, editing, or running commands, read and follow `GEMINI.md` at
this workspace root. It is the canonical source for all PulsarWiki project
instructions.

End each wiki page you create or edit with a two-sentence **AI declaration**.
Name the tool, provider, model or version if known, and date or period in the
first sentence. Describe the work in the second and mention prior author approval
when confirmed. Follow the template in [GEMINI.md](GEMINI.md#page-format).
